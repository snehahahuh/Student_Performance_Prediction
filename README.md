# Student Performance Prediction

## Problem Statement
Predict student academic performance using factors such as study hours, attendance, previous score and assignment performance.

## Objective
To develop a machine learning prototype that predicts whether a student is likely to Pass or Fail.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Decision Tree

## Methodology
1. Collect student performance data.
2. Prepare and load the dataset.
3. Select relevant input features.
4. Train a Decision Tree classification model.
5. Predict student performance.
6. Evaluate the model using accuracy.

## Input
- Hours Studied
- Attendance
- Previous Score
- Assignments

## Output
The system predicts the student's final result as Pass or Fail.

## Future Scope
The system can be improved using larger datasets, additional student-related features and different machine learning algorithms.
